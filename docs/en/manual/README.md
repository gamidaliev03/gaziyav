Three rules apply everywhere:

1. **Every change is one undo step.** <kbd>⌘Z</kbd> restores the state before it; <kbd>⇧⌘Z</kbd> redoes it. Claude's changes too.
2. **No need to save.** Every change is on disk within a quarter of a second. <kbd>⌘S</kbd> saves at once if you want.
3. **<kbd>Esc</kbd> never takes you out of the editor.** Each press does one thing, in this order: cancels the drag or trim in progress, closes what is open, clears the selection.
