Three rules hold everywhere and are worth knowing first:

1. **Every change is one undo step.** <kbd>⌘Z</kbd> brings back the state before it exactly; <kbd>⇧⌘Z</kbd> the state after. This is true for Claude's changes too.
2. **Nothing to save.** A change is written to disk within a quarter of a second; <kbd>⌘S</kbd> saves at once if you like.
3. **<kbd>Esc</kbd> never navigates away.** It cancels the gesture in your hand, then closes what is open, then clears the selection.
