# Post from the editor

[← Manual](README.md)

**What it is for.** Publishing the finished video without leaving Gaziyav.

**How.**
1. The arrow beside **Export** (top right) → **Post to Shorts, Reels, TikTok…**.
2. Pick YouTube, Instagram or TikTok; write the title, the description and the tags (or let Gaziyav AI write them — an [extra](extras.md)); choose public, unlisted or private, now or later.
3. The platform's own upload page opens inside the app, in its own window. The first time, you sign in there yourself.

**Rules that surprise people.**
- Gaziyav never sees your password: you type it into the platform's own page.
- A project that is not vertical can be posted as a 9:16 copy (a box in the Post sheet).
- Scheduled posts wait in Gaziyav's own queue on this Mac.
- The same menu has **Export and share**: it exports, then hands the file to the system share sheet.

**Limits.** Desktop app only — not in the browser edition. [Claude](claude.md) can post too, but only after you say yes.
