# Keyframes

[← Manual](README.md)

**What it is for.** Animating any parameter over time: position, scale, rotation, opacity, volume, effect values.

**How.**
- Add / remove keyframes at the playhead for every animated parameter: <kbd>⌥⇧K</kbd>. Or the keyframe button beside a parameter in the inspector.
- Previous / next keyframe: <kbd>⌥;</kbd> / <kbd>⌥'</kbd>.
- Easing on the selected keyframes: easy ease <kbd>F9</kbd>, ease in <kbd>⇧F9</kbd>, ease out <kbd>⇧⌘F9</kbd>, linear <kbd>⌥F9</kbd>, hold <kbd>⌃⌥H</kbd>.
- Delete all on the parameter <kbd>⌥⌫</kbd>; on the clip <kbd>⌥⇧⌫</kbd>.
- Reset transform (position, scale, rotation and their keyframes): <kbd>⌥⇧R</kbd>.
- Show / hide the keyframe panel: <kbd>⌥K</kbd>.

**Ready-made moves.** Push in, pull out, pans, tilts, Ken Burns, shake and punch-in are named camera moves — ask [Claude](claude.md) for one, and it writes them as ordinary keyframes you can edit.
