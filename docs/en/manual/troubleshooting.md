# Troubleshooting

[← Manual](README.md)

| What you see | What to do |
|---|---|
| macOS: «Gaziyav can't be opened» on the first start | System Settings → Privacy & Security → **Open Anyway**, then **Open**. You only do this once. |
| Claude says it cannot reach Gaziyav | Open Gaziyav; Settings → Services → Claude → **Connect again**; then ask again. |
| Claude's connector is not in Claude for Mac | Press **Connect Claude** again and accept the install in Claude's window. |
| Captions or Remove pauses say the speech model is missing | It downloads once (574 MB). Wait for the download to finish, or download it in Settings → Services. |
| An on-device feature will not download | Check the network. Gaziyav tries hf-mirror.com when Hugging Face cannot be reached. |
| A link download stops | Retry it on its tile in Media. If YouTube asks you to sign in, pick a browser where you are signed in. |
| Export is slow | Settings → Performance → «Speed up hardware encoding». |
| A paid run asks for confirmation | Its price is above your limit. Raise the limit in Settings → Services, or confirm this run. |

More: [the full troubleshooting guide](../troubleshooting.md) · [FAQ](../faq.md).
