# Troubleshooting

[← Manual](README.md)

| What you see | What to do |
|---|---|
| macOS: «Gaziyav can't be opened» on the first start | System Settings → Privacy & Security → **Open Anyway**, then **Open**. Once. |
| Claude says it cannot reach Gaziyav | Open Gaziyav; Settings → AI → Claude → **Connect again**; then ask again. |
| Claude's connector is not in Claude for Mac | Press **Connect Claude** again and accept the install in Claude's window. |
| Captions or Remove pauses say the speech model is missing | It is fetched once (574 MB). Allow the download when asked, or install it in Settings → AI. |
| An on-device feature cannot download | Check the network; Gaziyav tries hf-mirror.com when Hugging Face cannot be reached. |
| A link download stops | Retry on its tile in Media; if YouTube asks for a sign-in, pick a browser you are signed in with. |
| Export is slow | Settings → Performance → «Speed up hardware encoding». |
| A paid run asks again | It is above your limit: raise it in Settings → AI, or confirm once. |

More: [the full troubleshooting guide](../troubleshooting.md) · [FAQ](../faq.md).
