# Speed

[← Manual](README.md)

**What it is for.** Slow motion, time-lapse, ramps, freeze frames, reverse.

**How.**
- Speed / Duration: select a clip → <kbd>⌘R</kbd>. Type a rate or a new length.
- In the speed controls: keep the voice's pitch when the speed changes; smooth slow motion with optical flow.
- Speed curves: change the speed inside one clip, in the inspector.
- Freeze frame at the playhead: <kbd>⌥F</kbd> (three seconds, the clip continues after it).
- Reverse: find «Reverse» with <kbd>⌘K</kbd>. Run it again to play the clip forward.

**Good to know.**
- On the main track a faster clip gets shorter, and the magnet closes the gap after it.
- Exports with frame smoothing stay exact to the frame: 72 of 72 export cases checked.
