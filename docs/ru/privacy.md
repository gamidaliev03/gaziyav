# Приватность: что, куда и когда отправляется

[English](../en/privacy.md) · **Русский**

Коротко: **проекты и медиа остаются на вашем компьютере.** Что-то уходит, только когда вы пользуетесь функцией, которой нужен интернет, — и тогда только то, что нужно этой функции, и только в тот сервис, который она называет. Аккаунта Gaziyav нет, сервера Gaziyav нет, аналитики, статистики использования и отчётов о сбоях — тоже.

Эта страница написана по коду. Если найдёте запрос, которого здесь нет, [сообщите об ошибке](https://github.com/gamidaliev03/gaziyav/issues/new?template=bug.yml).

## Что остаётся на компьютере

- **Проекты, медиа, версии, голоса и настройки** — в `~/Library/Application Support/Gaziyav` на macOS. Импортированные файлы копируются в проект клонами APFS, которые не занимают лишнего места.
- **Монтаж, просмотр, эффекты, титры, цвет, экспорт** — всё считается локально.
- **Субтитры, очистка голоса, разделение голоса и музыки, смена голоса, удаление объектов** — локальные модели на Mac.
- **Треки и звуки из библиотеки**, которые вы уже брали, — в кэше на вашем диске.
- **Отчёты о сбоях** остаются на диске: отправка отключена в самом коде.
- **Ваши ключи** (fal.ai, kie.ai, ArgoLink, Pexels, Pixabay) — хранятся зашифрованными на вашем Mac, в папке самого приложения, и доступны только вашей учётной записи. Приложение показывает только четыре последних символа.

## Что уходит, когда и куда

| Когда вы… | Что отправляется | Куда |
|---|---|---|
| запускаете липсинк | **участки с речью** из обрезанного клипа (перекодированные в H.264) и звук для губ; для клона — образец голоса | fal.ai (хранилище, затем модель) |
| запускаете озвучку, клон, картинку, видео, замену лица | текст, образец, картинку-образец или кусок клипа — то, что нужно этой функции | fal.ai, либо kie.ai / ArgoLink, если выбрана их модель |
| пользуетесь агентом, ИИ-сценарием или переводом для дубляжа | текст запроса и нужные ему сведения о проекте (названия, длины, расшифровка — если попросили) | эндпоинт OpenRouter в fal.ai → выбранная вами модель |
| импортируете по ссылке | ссылку (и обычные запросы этого сайта) | сам сайт, через yt-dlp |
| впервые пользуетесь загрузчиком ссылок или YouTube перестал отдавать видео | проверку новой версии yt-dlp — её принимают, только если она подписана ключом самого yt-dlp, не чаще раза в день | github.com (выпуски yt-dlp) |
| впервые берёте трек или звук из библиотеки | запрос на скачивание | Hugging Face автора; файлы Mixkit — с mixkit.co; каждый файл сверяется по SHA-256 |
| открываете функцию, локальной модели которой ещё нет | запрос на скачивание | Hugging Face, в основном репозиторий моделей автора (запасной — hf-mirror.com), несколько файлов — у исходного автора модели; каждый файл сверяется по размеру и SHA-256 |
| ищете стоковое видео | слова поиска | Pexels / Pixabay (с вашими ключами) и Викисклад |
| впервые используете анимированную графику, которой нужен рендерер | разовое скачивание рендерера (закреплённая версия, сверка SHA-256) | хранилище Chrome for Testing от Google |
| публикуете | экспортированное видео | страница самой площадки, в окне, где вы вошли сами |

Что поставщики ИИ делают с полученным, определяют их собственные условия: [fal.ai](https://fal.ai), а также kie.ai / ArgoLink, если вы ими пользуетесь.

## Липсинк

Отправляются только участки, где кто-то говорит, — никогда не тишина и не остальной проект. Из ответа Gaziyav берёт только область лица, а везде вне неё остаются ваши исходные пиксели. Подробно: [Липсинк → Что уходит с компьютера](lipsync.md#что-уходит-с-компьютера).

## Gaziyav в браузере

[Gaziyav в браузере](https://gamidaliev03.github.io/gaziyav/editor/) — статическая страница: за ней нет сервера, только файлы, которые раздаёт GitHub Pages.

- **Ваши медиа никуда не загружаются.** Открытые файлы читает сама страница внутри вкладки, и там они остаются.
- **Проекты** хранятся в хранилище этого браузера на вашем компьютере (IndexedDB, local storage). Если очистить данные сайта в браузере, они удалятся, так что экспортируйте то, что хотите сохранить.
- **После первого открытия** файлы редактора лежат в кэше браузера, поэтому он работает и без интернета.
- **Музыка и звуки:** каждый файл скачивается с Hugging Face автора (файлы Mixkit — с mixkit.co), когда понадобится впервые, и потом остаётся в этом браузере.
- **Субтитры из речи:** при первом «Создать» страница скачивает открытую модель речи Whisper с Hugging Face (это только скачивание: туда ничего не отправляется) и распознаёт звук сама, внутри вкладки.
- **Липсинк (бета), ИИ-фото и ИИ-видео на своём ключе:** вставленный ключ fal.ai хранится только в этом браузере и уходит только в fal.ai — вместе с тем, что нужно для задачи (кусок клипа и звук для липсинка; описание и выбранные картинки для генерации), и только когда вы нажимаете кнопку. Больше его не получает никто: ни этот сайт, ни GitHub.
