# Установка

[English](../en/install.md) · **Русский**

- [macOS](#macos): Apple silicon, macOS 14 Sonoma и новее
- [Любой другой компьютер](#любой-другой-компьютер-gaziyav-в-браузере): Gaziyav в браузере для Windows, Linux или Chromebook, ставить ничего не нужно

## macOS

1. Скачайте `Gaziyav-<версия>-arm64.dmg` со страницы [выпусков](https://github.com/gamidaliev03/gaziyav/releases/latest). **Только** оттуда.
2. Откройте `.dmg` и перетащите **Gaziyav** в **«Программы»**.
3. Запустите Gaziyav из «Программ».

Нужен Mac на Apple silicon (M1 и новее) и macOS 14 или новее.  Файл для скачивания один — та же полная сборка, в которой монтирует сам автор. Библиотека музыки и звуков и модели ИИ на устройстве в него не входят: каждый файл скачивается, когда понадобится впервые.

### Откуда берётся «Apple не удалось проверить…»

Так macOS встречает любое приложение, которое не прошло платную проверку Apple — нотаризацию. Gaziyav подписан, но пока не нотаризован (это в [планах](../../README.ru.md#что-дальше)). Предупреждение не значит, что файл испорчен. Но это настоящая защита, поэтому открывайте приложение так, только если скачали его со страницы выпусков этого репозитория.

### Первый запуск (macOS 15 Sequoia и новее)

В свежих версиях macOS «Control-клик → Открыть» проверку больше не обходит. Действуйте так, как советует Apple:

1. Один раз попробуйте открыть Gaziyav. macOS покажет предупреждение — нажмите **«Готово»**.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите вниз до раздела **«Безопасность»**. Рядом со строкой про Gaziyav нажмите **«Всё равно открыть»**. Кнопка видна примерно час после попытки запуска.
4. Введите пароль своей учётной записи и в следующем окне нажмите **«Открыть»**.

macOS это запомнит: дальше Gaziyav открывается двойным щелчком, как любое приложение.

### macOS 14 Sonoma

Control-клик (или правый клик) по Gaziyav в «Программах» → **«Открыть»** → **«Открыть»**. Если кнопки «Открыть» нет, воспользуйтесь способом через Системные настройки выше.

### «Приложение „Gaziyav“ повреждено, и его не удаётся открыть»

Обычно это значит, что файл скачался не полностью или изменился по дороге, а не что приложение сломано. По порядку:

1. Удалите приложение и `.dmg`, скачайте заново со страницы [выпусков](https://github.com/gamidaliev03/gaziyav/releases/latest) и сверьте контрольную сумму с той, что указана в описании выпуска:
   ```sh
   shasum -a 256 ~/Downloads/Gaziyav-*.dmg
   ```
2. Попробуйте шаги с **«Всё равно открыть»** выше.
3. **Крайний случай** — только для копии, у которой сумма совпала: снять с этого одного приложения отметку «скачано из интернета».
   ```sh
   xattr -dr com.apple.quarantine /Applications/Gaziyav.app
   ```
   Что делает команда: браузер помечает каждый скачанный файл флагом карантина, и macOS проверяет помеченные приложения при первом запуске. Команда снимает флаг только с Gaziyav, и macOS не станет делать для него эту проверку. Больше она ничего на Mac не меняет.

Не отключайте Gatekeeper для всей системы — ни ради этого приложения, ни ради другого.

### Обновление и удаление

Чтобы обновиться, скачайте новый `.dmg` и замените приложение в «Программах» — проекты останутся. Чтобы удалить, перенесите Gaziyav в Корзину. Данные лежат в `~/Library/Application Support/Gaziyav`; удалите и эту папку, если хотите стереть все проекты, модели и настройки.

## Любой другой компьютер: Gaziyav в браузере

Кроме приложения для Mac, есть только версия в браузере. На Windows, Linux, Chromebook и любом другом компьютере [откройте редактор в браузере](https://gamidaliev03.github.io/gaziyav/editor/): без установки и без аккаунта. После первого открытия он работает и без интернета. Лучше всего — свежий браузер на компьютере (Chrome, Edge).

**Что в нём есть:** таймлайн, титры, эффекты, переходы, фильтры, генераторы, вся библиотека музыки и звуков, темы, импорт и экспорт, субтитры из речи с удалением пауз, а ещё липсинк (бета), ИИ-фото и ИИ-видео на вашем ключе fal.ai.

**Только в приложении для Mac:** Claude в Gaziyav, остальной ИИ на устройстве (очистка голоса, удаление фона, ретушь и другое), клип по ссылке, публикация из редактора, голос из текста, моушн-графика и длинный тяжёлый экспорт.

Проекты в браузере лежат в хранилище этого браузера. Если очистить данные сайта, они удалятся, так что экспортируйте то, что хотите сохранить. Подробнее: [Gaziyav в браузере](manual/browser.md). Экскурсия слайдами: `https://gamidaliev03.github.io/gaziyav/tour/`.
