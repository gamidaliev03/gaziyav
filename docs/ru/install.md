## macOS

1. Скачайте `Gaziyav-<версия>-arm64.dmg` со страницы [выпусков](https://github.com/gamidaliev03/gaziyav/releases/latest). **Только** оттуда.
2. Откройте `.dmg` и перетащите **Gaziyav** в **«Программы»**.
3. Запустите Gaziyav из «Программ».

Нужен Mac на Apple silicon (M1 и новее) и macOS 14 или новее.

### Откуда берётся «Apple не удалось проверить…»

Так macOS встречает любое приложение, которое не прошло платную проверку Apple — нотаризацию. Gaziyav подписан, но пока не нотаризован (это в [планах](../../README.ru.md#что-дальше)). Само предупреждение не значит, что с файлом что-то не так, — но это настоящая защита, поэтому открывайте приложение так, только если скачали его со страницы выпусков этого репозитория.

### Первый запуск (macOS 15 Sequoia и новее)

В свежих версиях macOS трюк «Control-клик → Открыть» проверку больше не обходит. Действуйте так, как советует сама Apple:

1. Один раз попробуйте открыть Gaziyav. macOS покажет предупреждение — нажмите **«Готово»**.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите вниз до раздела **«Безопасность»**. Рядом со строкой про Gaziyav нажмите **«Всё равно открыть»**. Кнопка видна примерно час после попытки запуска.
4. Введите пароль своей учётной записи и в следующем окне нажмите **«Открыть»**.

macOS это запомнит: дальше Gaziyav открывается двойным щелчком, как любое приложение.

### macOS 14 Sonoma

Control-клик (или правый клик) по Gaziyav в «Программах» → **«Открыть»** → **«Открыть»**. Если кнопки «Открыть» нет — способ через Системные настройки выше.

### «Приложение „Gaziyav“ повреждено, и его не удаётся открыть»

Обычно это значит, что файл скачался не полностью или изменился по дороге, а не что приложение сломано. По порядку:

1. Удалите приложение и `.dmg`, скачайте заново со страницы [выпусков](https://github.com/gamidaliev03/gaziyav/releases/latest) и сверьте контрольную сумму с той, что указана в описании выпуска:
   ```sh
   shasum -a 256 ~/Downloads/Gaziyav-*.dmg
   ```
2. Попробуйте шаги с **«Всё равно открыть»** выше.
3. **Крайний случай** — только для копии, у которой сумма совпала: снять с этого одного приложения отметку «скачано из интернета».
   ```sh
   xattr -dr com.apple.quarantine /Applications/Gaziyav.app
   ```
   Что делает команда: браузер помечает каждый скачанный файл флагом карантина, и macOS проверяет помеченные приложения при первом запуске. Команда снимает флаг только с Gaziyav, и macOS не станет делать для него эту проверку. Больше она ничего на Mac не меняет.

Никогда не отключайте Gatekeeper для всей системы ради какого-либо приложения — и ради этого тоже.

### Обновление и удаление

Чтобы обновиться, скачайте новый `.dmg` и замените приложение в «Программах» — проекты останутся. Чтобы удалить, перенесите Gaziyav в Корзину. Данные лежат в `~/Library/Application Support/Gaziyav` — удалите и эту папку, если хотите стереть все проекты, модели и настройки.

## Любой другой компьютер: Gaziyav в браузере

Есть приложение для Mac и Gaziyav в браузере — больше скачивать нечего. На Windows, Linux, Chromebook и любом компьютере, кроме Mac, [откройте редактор в браузере](https://gamidaliev03.github.io/gaziyav/editor/): без установки, без аккаунта, без сервера. Он работает на вашем железе, файлы не покидают вкладку, а после первого открытия редактор работает и без интернета. Лучше всего — свежий браузер на компьютере (Chrome, Edge).

**Что в нём есть:** таймлайн с его грамматикой, титры, эффекты, переходы, фильтры, темы, импорт своих файлов и экспорт — и **липсинк (бета), на вашем ключе fal.ai**: ключ хранится только в этом браузере и уходит только в fal.ai.

**Только в приложении для Mac:** Claude в Gaziyav, бесплатный ИИ на устройстве (субтитры из речи, удаление пауз, очистка голоса и остальное), клип по ссылке, публикация прямо из редактора и длинный тяжёлый экспорт.

Проекты в браузере лежат в хранилище этого браузера: если очистить данные сайта, они пропадут — экспортируйте то, что хотите сохранить. Подробнее: [Gaziyav в браузере](manual/browser.md). Экскурсия слайдами открывается там же: `https://gamidaliev03.github.io/gaziyav/tour/`.
