# Таймлайн

[English](../en/timeline.md) · **Русский**

В проекте один таймлайн. Всё, что на нём лежит (видео, клип на верхней дорожке, звук, титр, субтитр, фигура, составной клип), подчиняется одним правилам.

## Правила

| Жест | Что делает — для любого клипа |
|---|---|
| Тянуть тело клипа | Сдвинуть |
| Тянуть край | Подрезать. Ручки видны с обеих сторон при любом масштабе; край под курсором подсвечивается. |
| <kbd>⌥</kbd> + перетаскивание | Копия |
| <kbd>⇧</kbd> + щелчок | Добавить к выделению |
| <kbd>⌘</kbd> + щелчок | Добавить или убрать из выделения |
| Держать <kbd>⌘</kbd> при перетаскивании | Тянуть свободно, без прилипания |
| <kbd>Esc</kbd> | Отменить начатый жест → закрыть открытое → снять выделение. На другой экран не уводит никогда. |
| Правый клик | Меню клипа, одинаковое для всех клипов |

Любое основное действие можно сделать **только клавиатурой** или **только трекпадом**.

## Три переключателя

- **Магнит** <kbd>P</kbd>: на основной дорожке нет дыр. Удалили или укоротили клип — всё сомкнулось; удлинили — следующие сдвинулись. На остальных дорожках удлинённый клип держит начало и упирается в соседа. Отмена помнит и магнит: при включённом магните <kbd>⌘Z</kbd> никогда не вернёт дыру.
- **Прилипание** <kbd>N</kbd>: края цепляются за склейки, курсор и маркеры.
- **Связь** <kbd>`</kbd>: собственный звук клипа ездит вместе с ним. Отделить звук — <kbd>⌃⇧S</kbd>.

## Подрезка

- **Выделение** <kbd>A</kbd>: на склейке левая зона — конец уходящего клипа, правая — начало входящего; <kbd>⌥</kbd> с любой стороны подрезает этот край со сдвигом. Инструмент выделения никогда не делает прокатку.
- **Инструмент подрезки** <kbd>T</kbd> (или держать <kbd>T</kbd>): прокатка склейки, подрезка края со сдвигом, прокрутка содержимого клипа.
- Выбрать край с клавиатуры: <kbd>⇧[</kbd> — конец уходящего, <kbd>⇧]</kbd> — начало входящего, <kbd>\\</kbd> — оба (прокатка). Дальше <kbd>,</kbd> <kbd>.</kbd> двигают на кадр, <kbd>⇧,</kbd> <kbd>⇧.</kbd> — на десять.
- Числом: <kbd>=</kbd> или <kbd>-</kbd>, затем кадры или таймкод, <kbd>↵</kbd>.
- **Подрезка на ходу:** <kbd>⇧/</kbd> крутит выбранную склейку по кругу, а подрезать её можно прямо во время просмотра — <kbd>J</kbd> <kbd>L</kbd> <kbd>,</kbd> <kbd>.</kbd>.
- **По курсору:** <kbd>Q</kbd> обрезает начало, <kbd>W</kbd> — конец. **Прокрутка:** <kbd>⌥,</kbd> <kbd>⌥.</kbd>.

Клип никогда не становится короче одного кадра и никогда не наезжает на соседа.

## Составные клипы

Выделите клипы → <kbd>⌥G</kbd> — составной клип. <kbd>⌘↓</kbd> открывает выделенный составной клип, <kbd>⌘↑</kbd> выводит обратно; курсор, масштаб и прокрутка родителя восстанавливаются уровень за уровнем. Копии составного клипа делят одно содержимое. <kbd>⌥⇧G</kbd> разбирает его.

Старые проекты с несколькими таймлайнами открываются так: лишние таймлайны становятся **составными клипами в «Медиа»**. Двойной щелчок открывает, перетаскивание ставит на таймлайн. Ничего не переделывается, пока вы не начнёте править, а версия «до объединения» сохраняется.

## Отмена

Каждое изменение — один шаг истории: одно <kbd>⌘Z</kbd> возвращает ровно то, что было до него, <kbd>⇧⌘Z</kbd> — то, что после. Автотесты прошли по всем командам, 930 запусков: каждое изменение оказалось одним шагом, и ни одно правило таймлайна не нарушилось. Модельный тест ещё и гоняет ядро редактора по 1 500 случайным цепочкам из 300 шагов с проверкой после каждого шага.

Правила, которые проверяются после каждого шага: клипы одной дорожки не перекрываются; каждый клип внутри своего исходника; на магнитной основной дорожке нет дыр; идентификаторы уникальны; в выделении только то, что есть; отмена и повтор совпадают байт в байт.

## Сохранение

Gaziyav сохраняет сам: новый клип — сразу, любую другую правку — через четверть секунды (не позже чем через три секунды, пока вы продолжаете править). Перетаскивание не считается изменением, пока вы не отпустили клип. <kbd>⌘S</kbd> сохраняет сразу, если хочется.
