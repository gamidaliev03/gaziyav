# Таймлайн

[← Руководство](README.md)

**Для чего.** Один проект — один таймлайн: магнитная главная дорожка для истории, дорожки выше — для титров, наложений и субтитров, ниже — для звука.

**Грамматика — одна для любого клипа** (видео, наложение, звук, титр, субтитр, фигура, составной клип):

| Жест | Значит |
|---|---|
| Тянуть тело | Двигать |
| Тянуть край | Обрезать (у каждого клипа ручки на обоих краях при любом масштабе) |
| <kbd>⌥</kbd> + тянуть | Копировать |
| <kbd>⇧</kbd> + щелчок / <kbd>⌘</kbd> + щелчок | Добавить к выделению / переключить в нём |
| Держать <kbd>⌘</kbd> при перетаскивании | Тащить свободно, без прилипания |
| Правый щелчок | Меню клипа — одинаковое для всех видов |
| <kbd>Esc</kbd> | Отменить жест → закрыть открытое → снять выделение |

**Самые короткие пути.**
- Разрезать у курсора <kbd>⌘B</kbd> (все дорожки <kbd>⇧⌘B</kbd>); инструмент «Лезвие» <kbd>B</kbd> режет там, где щёлкнули.
- Удалить <kbd>⌫</kbd>; удалить со сдвигом (закрыть дыру) <kbd>⇧⌫</kbd>.
- Копировать, вырезать, вставить <kbd>⌘C</kbd> <kbd>⌘X</kbd> <kbd>⌘V</kbd> (вставка встаёт у курсора и сдвигает следующие клипы); вставить поверх <kbd>⌥V</kbd>; дублировать <kbd>⌥D</kbd>.
- Сдвинуть на кадр <kbd>,</kbd> <kbd>.</kbd>, на десять <kbd>⇧,</kbd> <kbd>⇧.</kbd>.
- Выделить всё от курсора вперёд <kbd>]</kbd>, до курсора <kbd>[</kbd>; следующий / предыдущий клип <kbd>⌘→</kbd> <kbd>⌘←</kbd>.
- Масштаб <kbd>⌘=</kbd> <kbd>⌘-</kbd>, вместить всё <kbd>⇧Z</kbd>; включить / выключить клип <kbd>V</kbd>, заглушить <kbd>⇧V</kbd>.

**Три переключателя.**
- **Магнит** <kbd>P</kbd>: на главной дорожке нет дыр — удаление или укорочение смыкает, удлинение раздвигает. В других местах удлинённый клип держит начало и упирается в соседа. <kbd>⌘Z</kbd> никогда не возвращает дыру под включённым магнитом.
- **Прилипание** <kbd>N</kbd>: края цепляются за стыки, курсор и маркеры.
- **Связка** <kbd>`</kbd>: собственный звук клипа ходит вместе с ним; отцепить — <kbd>⌃⇧S</kbd>.

**Что удивляет.**
- Каждое изменение — ровно один шаг отмены; проверено команда за командой: 930 прогонов, ни одного нарушенного правила таймлайна.
- После каждого шага: клипы одной дорожки не перекрываются, каждый клип внутри своего исходника, на магнитной главной дорожке нет дыр.
- Клип не бывает короче одного кадра и не врастает в соседа.
