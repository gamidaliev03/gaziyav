# Таймлайн

[← Руководство](README.md)

**Для чего.** Один проект — один таймлайн: магнитная главная дорожка для истории, дорожки выше — для титров, наложений и субтитров, ниже — для звука.

**Одни и те же жесты для любого клипа** (видео, наложение, звук, титр, субтитр, фигура, составной клип):

| Жест | Значит |
|---|---|
| Тянуть клип | Двигать |
| Тянуть край | Подрезать (у каждого клипа ручки на обоих краях при любом масштабе) |
| <kbd>⌥</kbd> + тянуть | Копировать |
| <kbd>⇧</kbd> + щелчок / <kbd>⌘</kbd> + щелчок | Добавить к выделению / переключить в нём |
| Держать <kbd>⌘</kbd> при перетаскивании | Тащить свободно, без прилипания |
| Правый щелчок | Меню клипа, одинаковое для клипов любого вида |
| <kbd>Esc</kbd> | Отменить текущее перетаскивание → закрыть открытое → снять выделение |

**Самые короткие пути.**
- Разрезать у курсора <kbd>⌘B</kbd> (все дорожки <kbd>⇧⌘B</kbd>); инструмент «Лезвие» <kbd>B</kbd> режет там, где щёлкнули.
- Удалить <kbd>⌫</kbd>; удалить со сдвигом (закрыть промежуток) <kbd>⇧⌫</kbd>.
- Копировать, вырезать, вставить <kbd>⌘C</kbd> <kbd>⌘X</kbd> <kbd>⌘V</kbd> (вставка встаёт у курсора и сдвигает следующие клипы); вставить поверх <kbd>⌥V</kbd>; дублировать <kbd>⌥D</kbd>.
- Сдвинуть на кадр <kbd>,</kbd> <kbd>.</kbd>, на десять <kbd>⇧,</kbd> <kbd>⇧.</kbd>.
- Выделить всё от курсора вперёд <kbd>]</kbd>, до курсора <kbd>[</kbd>; следующий / предыдущий клип <kbd>⌘→</kbd> <kbd>⌘←</kbd>.
- Масштаб <kbd>⌘=</kbd> <kbd>⌘-</kbd>, вместить всё <kbd>⇧Z</kbd>; включить / выключить клип <kbd>V</kbd>, заглушить <kbd>⇧V</kbd>.

**Три переключателя.**
- **Магнит** <kbd>P</kbd>: на главной дорожке нет промежутков. Если удалить или укоротить клип, остальные смыкаются; если удлинить — раздвигаются. На других дорожках удлинённый клип сохраняет начало и упирается в соседний. <kbd>⌘Z</kbd> никогда не возвращает промежуток, пока магнит включён.
- **Прилипание** <kbd>N</kbd>: края цепляются за стыки, курсор и маркеры.
- **Связка** <kbd>`</kbd>: собственный звук клипа двигается вместе с ним; отцепить — <kbd>⌃⇧S</kbd>.

**Полезно знать.**
- Каждое изменение — ровно один шаг отмены. Автоматический тест прогоняет каждую команду и после каждой проверяет правила таймлайна: 930 прогонов, ни одного нарушения.
- Эти правила соблюдаются после каждого шага: клипы одной дорожки не перекрываются, каждый клип остаётся в пределах исходника, на главной дорожке нет промежутков.
- Клип не бывает короче одного кадра и не наезжает на соседний.
