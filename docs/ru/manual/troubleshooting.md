# Если что-то не так

[← Руководство](README.md)

| Что видите | Что делать |
|---|---|
| macOS при первом запуске: «Не удаётся открыть Gaziyav» | Системные настройки → Конфиденциальность и безопасность → **«Всё равно открыть»**, затем **«Открыть»**. Это нужно сделать один раз. |
| Claude пишет, что не может связаться с Gaziyav | Откройте Gaziyav; Настройки → ИИ → Claude → **«Подключить заново»**; повторите просьбу. |
| В Claude для Mac нет коннектора | Нажмите **«Подключить Claude»** ещё раз и подтвердите установку в окне Claude. |
| Субтитры или «Удалить паузы» пишут, что нет модели речи | Она скачивается один раз (574 МБ). Дождитесь конца загрузки или скачайте её в Настройках → ИИ. |
| Не скачивается функция ИИ на устройстве | Проверьте сеть. Если Hugging Face недоступен, Gaziyav пробует зеркало hf-mirror.com. |
| Загрузка по ссылке остановилась | Повторите её на плитке в «Медиа». Если YouTube просит войти, выберите браузер, в котором вы вошли в аккаунт. |
| Экспорт медленный | Настройки → «Производительность» → «Ускорить аппаратное кодирование». |
| Платный запуск просит подтверждения | Его цена выше вашего лимита. Поднимите лимит в Настройках → ИИ или подтвердите этот запуск. |
