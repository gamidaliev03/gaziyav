# Если что-то не так

[← Руководство](README.md)

| Что видите | Что делать |
|---|---|
| macOS при первом запуске: «Не удаётся открыть Gaziyav» | Системные настройки → Конфиденциальность и безопасность → **«Всё равно открыть»**, затем **«Открыть»**. Один раз. |
| Claude пишет, что не достучался до Gaziyav | Откройте Gaziyav; Настройки → ИИ → Claude → **«Подключить заново»**; спросите ещё раз. |
| В Claude для Mac нет коннектора | Ещё раз **«Подключить Claude»** и подтвердите установку в окне Claude. |
| Субтитры или «Удалить паузы» пишут, что нет модели речи | Она скачивается один раз (574 МБ). Разрешите загрузку или поставьте её в Настройках → ИИ. |
| Функция на устройстве не скачивается | Проверьте сеть; если Hugging Face недоступен, Gaziyav пробует hf-mirror.com. |
| Загрузка по ссылке остановилась | Повторите на её плитке в «Медиа»; если YouTube просит вход — выберите браузер, где вы вошли. |
| Экспорт медленный | Настройки → «Производительность» → «Ускорить аппаратное кодирование». |
| Платный запуск переспрашивает | Цена выше вашего лимита: поднимите его в Настройках → ИИ или подтвердите один раз. |
