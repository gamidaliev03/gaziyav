# Составные клипы

[← Руководство](README.md)

**Для чего.** Чтобы работать с группой клипов как с одним — вложенная последовательность, которую можно двигать, обрезать, красить и использовать снова.

**Как.**
- Сделать: выделите клипы → <kbd>⌥G</kbd>.
- Открыть: выделите → <kbd>⌘↓</kbd>. Выйти: <kbd>⌘↑</kbd> — курсор, масштаб и прокрутка родителя возвращаются, уровень за уровнем.
- Разобрать: <kbd>⌥⇧G</kbd>.
- Сгруппировать без вложения: <kbd>⌘G</kbd>, разгруппировать <kbd>⇧⌘G</kbd>.

**Что удивляет.**
- Копии составного клипа делят одно содержимое: поменяли внутри одного — поменялись все.
- Старые проекты с несколькими таймлайнами открываются так: лишние таймлайны лежат составными клипами в «Медиа» — двойной щелчок открывает, перетаскивание ставит. Ничего не переделывается, пока вы не начнёте править, и версия «до объединения» сохраняется.
