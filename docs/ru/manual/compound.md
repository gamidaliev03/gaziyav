# Составные клипы

[← Руководство](README.md)

**Для чего.** Работать с группой клипов как с одним клипом. Это вложенная последовательность: её можно двигать, подрезать, красить и использовать снова.

**Как.**
- Сделать: выделите клипы → <kbd>⌥G</kbd>.
- Открыть: выделите → <kbd>⌘↓</kbd>. Выйти: <kbd>⌘↑</kbd> — курсор, масштаб и прокрутка родителя возвращаются, уровень за уровнем.
- Разобрать: <kbd>⌥⇧G</kbd>.
- Сгруппировать без вложения: <kbd>⌘G</kbd>, разгруппировать <kbd>⇧⌘G</kbd>.

**Полезно знать.**
- У копий составного клипа одно содержимое на всех: поменяли внутри одной — поменялись все.
- Старый проект с несколькими таймлайнами открывается так: лишние таймлайны лежат в «Медиа» составными клипами. Двойной щелчок открывает такой клип, перетаскивание ставит его на таймлайн. Пока вы не начнёте править, ничего не переделывается, а версия «до объединения» сохраняется.
