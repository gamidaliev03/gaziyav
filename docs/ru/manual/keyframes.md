# Ключевые кадры

[← Руководство](README.md)

**Для чего.** Анимировать любой параметр во времени: положение, масштаб, поворот, прозрачность, громкость, значения эффектов.

**Как.**
- Поставить / убрать ключи у курсора на всех анимируемых параметрах: <kbd>⌥⇧K</kbd> или кнопка ключа рядом с параметром в инспекторе.
- Предыдущий / следующий ключ: <kbd>⌥;</kbd> / <kbd>⌥'</kbd>.
- Сглаживание выделенных ключей: плавно <kbd>F9</kbd>, плавный вход <kbd>⇧F9</kbd>, плавный выход <kbd>⇧⌘F9</kbd>, линейно <kbd>⌥F9</kbd>, удержание <kbd>⌃⌥H</kbd>.
- Удалить все ключи параметра <kbd>⌥⌫</kbd>; клипа <kbd>⌥⇧⌫</kbd>.
- Сбросить трансформацию (положение, масштаб, поворот и их ключи): <kbd>⌥⇧R</kbd>.
- Показать / скрыть панель ключей: <kbd>⌥K</kbd>.

**Готовые движения.** Наезд, отъезд, панорама, наклон, Кен Бёрнс, тряска и резкий наезд — это готовые движения камеры. Попросите [Claude](claude.md), и он добавит движение обычными ключевыми кадрами, которые можно править.
