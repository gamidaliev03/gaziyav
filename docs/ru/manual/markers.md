# Маркеры

[← Руководство](README.md)

**Для чего.** Булавки на таймлайне: биты, заметки, места, куда вернуться; прилипание цепляется за них.

**Как.**
- Поставить у курсора <kbd>M</kbd>; другим цветом <kbd>⌥M</kbd>.
- Следующий / предыдущий <kbd>⇧M</kbd> / <kbd>⌥⇧M</kbd>.
- Отметить бит, пока играет музыка: <kbd>⌘J</kbd>. Биты музыкального клипа можно найти и автоматически ([ИИ на устройстве](ondevice-ai.md)).
- Отрезок: <kbd>I</kbd> <kbd>O</kbd>, снять <kbd>⌥X</kbd>, перейти <kbd>⇧I</kbd> <kbd>⇧O</kbd>, проиграть отрезок <kbd>/</kbd>; отрезок по клипу <kbd>⇧X</kbd>.
- Поднять отрезок (оставить дыру) <kbd>;</kbd>; вынуть отрезок (сомкнуть) <kbd>'</kbd>.

**Что удивляет.** «Поднять» и «вынуть» действуют на все дорожки внутри отрезка.
