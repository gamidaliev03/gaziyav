# Темы

[← Руководство](README.md)

**Для чего.** Внешний вид самого редактора. Ваше видео тема не меняет.

**Как.** Настройки → **«Темы»**: выберите плитку. Если у темы есть светлый и тёмный вариант, выберите нужный.

- Десять тем с полным оформлением: **Пиксель**, **Неон**, **Комикс**, **Сакура**, **Роза**, **Арена**, **Плёнка**, **Аналог**, **Терминал**, **95**.
- Шесть палитр: «Жидкое стекло», «Матовое стекло», «Строгая», «Полночь», «Песок», «Высокий контраст». По умолчанию — «Минимал».

**Полезно знать.**
- Тема меняет поверхности, иконки и анимацию интерфейса. Раскладку, клавиши и цвета вашего видео она не меняет.
- Плеер и миниатюры нейтральны в любой теме.
