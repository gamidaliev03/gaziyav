Три правила действуют везде:

1. **Любая правка — один шаг отмены.** <kbd>⌘Z</kbd> возвращает всё как было до неё, <kbd>⇧⌘Z</kbd> повторяет её. Правки Claude — тоже.
2. **Сохранять не нужно.** Каждая правка оказывается на диске за четверть секунды. <kbd>⌘S</kbd> сохраняет сразу, если хотите.
3. **<kbd>Esc</kbd> не выводит из редактора.** Каждое нажатие делает одно действие, по порядку: отменяет текущее перетаскивание или подрезку, закрывает открытое, снимает выделение.
