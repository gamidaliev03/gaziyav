Три правила действуют везде, их стоит знать сразу:

1. **Любая правка — один шаг отмены.** <kbd>⌘Z</kbd> возвращает состояние до неё в точности, <kbd>⇧⌘Z</kbd> — после. Правки Claude — тоже.
2. **Сохранять не нужно.** Изменение записывается на диск за четверть секунды; <kbd>⌘S</kbd> сохраняет сразу, если хочется.
3. **<kbd>Esc</kbd> никуда не уводит.** Он отменяет жест в руке, потом закрывает открытое, потом снимает выделение.
