# Субтитры

[← Руководство](README.md)

**Для чего.** Субтитры из речи в ваших клипах с точностью до слова. Речь распознаётся на вашем Mac, бесплатно.

**Как.**
1. Вкладка **«Текст»** → **«Субтитры»** → **«Автосубтитры»**.
2. Язык речи (или «Определить автоматически»), слов в строке, двуязычные субтитры, если нужен второй язык под первым.
3. **«Сгенерировать»**. Отметьте «Удалить текущие субтитры», чтобы заменить сделанные раньше субтитры.

Там же: **«Шаблоны»** (стили субтитров), **«Автотекст песни»**, **«Добавить субтитры»** вручную и **«Удалить паузы»** — эта кнопка вырезает тишину и слова-паразиты из выделенного клипа с речью.

**Полезно знать.**
- При первом запуске модель речи (574 МБ) один раз скачивается с Hugging Face и сверяется по SHA-256. Дальше субтитры работают без интернета.
- «Удалить паузы» укорачивает паузы длиннее 400 мс до естественной паузы говорящего, а не до нуля. Режет внутри тишины, никогда по слову или вдоху, ставит на стыках плавные переходы звука по 30 мс и сохраняет синхрон связанного звука. Субтитры и титры сдвигаются вместе с монтажом; музыка не режется.
- Одно <kbd>⌘Z</kbd> отменяет весь проход.

**Ограничения.** Речь, записанная в шумной комнате, распознаётся хуже. Сначала очистите голос ([Звук](sound.md)).
