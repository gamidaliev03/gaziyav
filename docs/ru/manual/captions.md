# Субтитры

[← Руководство](README.md)

**Для чего.** Субтитры по словам из речи ваших клипов — распознаются на вашем Mac, бесплатно.

**Как.**
1. Вкладка **«Текст»** → **«Субтитры»** → **«Автосубтитры»**.
2. Язык речи (или «Определить автоматически»), слов в строке, двуязычные субтитры, если нужен второй язык под первым.
3. **«Сгенерировать»**. Отметьте «Удалить текущие субтитры», чтобы заменить прежний проход.

Там же: **«Шаблоны»** (стили субтитров), **«Автотекст песни»**, **«Добавить субтитры»** вручную и **«Удалить паузы»** — вырезает тишину и слова-паразиты в выделенном разговорном клипе.

**Что удивляет.**
- Первый запуск один раз скачивает модель речи (574 МБ) с Hugging Face со сверкой по SHA-256; потом всё работает без интернета.
- «Удалить паузы» укорачивает длинные паузы (больше 400 мс) до естественной паузы говорящего, а не до нуля, режет внутри тишины (никогда по слову или вдоху), ставит 30-мс переходы звука на стыках и держит связанный звук в синхроне. Субтитры и титры едут следом; музыку не режет.
- Одно <kbd>⌘Z</kbd> отменяет весь проход.

**Ограничения.** Речь в шумной комнате распознаётся хуже: сначала очистите голос ([Звук](sound.md)).
