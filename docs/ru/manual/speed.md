# Скорость

[← Руководство](README.md)

**Для чего.** Замедление, ускорение, разгоны, стоп-кадры, обратный ход.

**Как.**
- Скорость / длительность: выделите клип → <kbd>⌘R</kbd>. Введите скорость или новую длину.
- В параметрах скорости: сохранять высоту голоса при смене скорости; плавное замедление с оптическим потоком.
- Кривые скорости: разгон и торможение внутри одного клипа, в инспекторе.
- Стоп-кадр у курсора: <kbd>⌥F</kbd> (три секунды, дальше клип продолжается).
- Задом наперёд: найдите «Задом наперёд» через <kbd>⌘K</kbd>. Повторный запуск возвращает обычный ход.

**Полезно знать.**
- На главной дорожке ускоренный клип становится короче, и магнит закрывает промежуток после него.
- Экспорт с плавными кадрами остаётся точным до кадра: проверено 72 из 72 вариантов.
