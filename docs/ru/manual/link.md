# Клип по ссылке

[← Руководство](README.md)

**Для чего.** Кусок видео из сети — прямо в монтаж, без скачивания целого ролика.

**Как.**
1. В «Медиа» откройте окно ссылки (<kbd>⇧⌘Y</kbd> или пункт меню **«Импорт по ссылке (YouTube)…»**) и вставьте ссылку — YouTube, TikTok, Instagram и другие сайты, которые понимает yt-dlp, — или введите слова для поиска по YouTube.
2. Отметьте кусок: <kbd>I</kbd> — начало, <kbd>O</kbd> — конец, или потяните жёлтые края на полосе.
3. Добавьте. Скачается только этот кусок; его плитка сразу появляется в «Медиа» и заполняется по мере загрузки; до таймлайна — одно перетаскивание. Попросите [Claude](claude.md) — он положит кусок на таймлайн сам.

**Что удивляет.**
- Загрузка переживает перезагрузку окна: она возвращается на свою плитку, её можно повторить.
- Если YouTube просит войти, Gaziyav может взять вход из браузера на этом Mac (Chrome, Safari, Firefox, Edge, Brave, Opera) — какой, выбираете вы.
- Ссылка уходит самому сайту, через встроенный yt-dlp; ни через какой наш сервер ничего не идёт.

**Ограничения.** Для материала, который вы вправе использовать. Только в приложении для компьютера — в браузерной версии нет.
