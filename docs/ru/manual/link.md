# Клип по ссылке

[← Руководство](README.md)

**Для чего.** Взять в монтаж кусок видео из интернета, не скачивая ролик целиком.

**Как.**
1. В «Медиа» откройте окно ссылки (<kbd>⇧⌘Y</kbd> или пункт меню **«Импорт по ссылке (YouTube)…»**). Вставьте ссылку с YouTube, TikTok, Instagram или другого сайта, который поддерживает yt-dlp, либо введите слова для поиска по YouTube.
2. Отметьте отрезок: <kbd>I</kbd> — начало, <kbd>O</kbd> — конец, или потяните жёлтые края на полосе. Если тянуть отрезок за середину, он сдвигается целиком.
3. Добавьте его. Скачается только этот отрезок. Его плитка сразу появится в «Медиа» и заполнится по мере загрузки; перетащите её на таймлайн. Если попросить [Claude](claude.md), он сам положит кусок на таймлайн.

**Полезно знать.**
- Загрузка не пропадает, если окно перезагрузилось: она возвращается на свою плитку, и её можно повторить.
- Если YouTube просит войти, Gaziyav может взять ваш вход из браузера на этом Mac (Chrome, Safari, Firefox, Edge, Brave, Opera). Браузер выбираете вы.
- Отрезок скачивается прямо с сайта через встроенный yt-dlp, а не через сервер Gaziyav.

**Ограничения.** Только в приложении для Mac, в браузерной версии этого нет. Берите только тот материал, на который у вас есть права.
