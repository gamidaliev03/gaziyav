# Дополнительно на своём ключе

[← Руководство](README.md)

**Для монтажа не нужно — есть, если захотите.** Gaziyav умеет звать платные нейросети через ваш собственный ключ [fal.ai](https://fal.ai): липсинк, голос из текста, клон голоса, дубляж, картинки и видео из текста или картинки, замену лица и встроенного агента (Gaziyav AI) на платной модели.

## Настройка

Настройки → **«ИИ»** → вставьте ключ fal.ai. Он хранится зашифрованным в связке ключей macOS; страница видит только последние четыре символа. Задайте лимит: выше него (по умолчанию 1 $) запуск один раз переспросит.

## Сколько стоит

Каждый запуск fal выставляет вам по своему прайсу — Gaziyav ничего не добавляет. Цена — на кнопке до нажатия.

| Задача | Модель по умолчанию | Прайс (USD) |
|---|---|---|
| Липсинк | LatentSync (ByteDance) | 0,20 $ за клип до 40 с, дальше 0,005 $/с |
| Голос из текста | Qwen3 TTS 1.7B | 0,09 $ за 1000 символов |
| Клон голоса | Qwen3 voice clone | 0,0008 $ за минуту образца |
| Картинка | Seedream 4.0 | 0,03 $ за картинку |
| Видео | Seedance 1.0 Pro Fast | 0,0216 $/с в 720p |
| Замена лица | PixVerse Swap | 0,20 $ за клип до 5 с |
| Встроенный агент, сценарии, перевод | Gemini 2.5 Flash | по токенам (0,30 $ за 1 млн входных) |

Другие модели для каждой задачи, с ценами, — в меню моделей и в разделе [Настройка ИИ и цены](../ai.md).

## Липсинк по шагам

1. Выделите клип с лицом → <kbd>⌥L</kbd> (или «Липсинк…» в меню клипа, или <kbd>⌘K</kbd> «липсинк»). Липсинк — один из ИИ-инструментов в блоке инструментов инспектора; любой из этих путей открывает его.
2. Впишите, что человек должен сказать. Голос клонируется из самого клипа.
3. <kbd>⌘</kbd><kbd>↵</kbd>. Цена была на кнопке.

- Отправляются только участки с речью, обратно вклеивается только лицо — поверх ваших исходных кадров: трёхминутный клип, где 64 % тишины, стоит **60 ¢ вместо 90,5 ¢**.
- Реплика 2–24 с на модели по умолчанию: **20 ¢**.
- Новые слова заменяют старую речь: клип принимает длину голоса, следующие клипы идут за магнитом, одно <kbd>⌘Z</kbd> отменяет всё.
- Несколько клипов разом (три параллельно, остальные в очереди); оплаченный запуск переживает выход из приложения.
- Сначала **«Проба»** на 3 секунды (примерно 2,6 ¢) — играет прямо в панели; в списке моделей у каждой видна цена для этого клипа.
- Каждый результат — **дубль** клипа: <kbd>⇧⌥L</kbd> переключает оригинал и дубль, **«Ещё дубль»** делает следующий; янтарная метка скажет, когда губы перестали совпадать со звуком.
