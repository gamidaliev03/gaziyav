# Платный ИИ на своём ключе

[← Руководство](README.md)

**Для монтажа это не нужно.** Gaziyav может запускать платные нейросети через ваш собственный ключ [fal.ai](https://fal.ai): липсинк, голос из текста, клон голоса, дубляж, картинки и видео из текста или картинки и замену лица. Другие сервисы (голоса, картинки, видео, поиск) — в **«Настройки → Сервисы»**, каждый на своём ключе. Работа с текстом (Gaziyav AI) здесь не оплачивается: в приложении для Mac она идёт через подключённого вами Claude ([Claude в Gaziyav](claude.md)).

## Настройка

Настройки → **«Сервисы»** → вставьте ключ fal.ai. Он хранится зашифрованным на вашем Mac, в папке самого приложения; интерфейс редактора получает только последние четыре символа. Задайте лимит трат: если запуск дороже (по умолчанию лимит 1 $), редактор один раз переспросит.

## Сколько стоит

fal выставляет вам счёт за каждый запуск по своему прайсу; Gaziyav ничего не добавляет. Цена видна на кнопке до нажатия.

| Задача | Модель по умолчанию | Прайс (USD) |
|---|---|---|
| Липсинк | LatentSync (ByteDance) | 0,20 $ за клип до 40 с, дальше 0,005 $/с |
| Голос из текста | Qwen3 TTS 1.7B | 0,09 $ за 1000 символов |
| Клон голоса | Qwen3 voice clone | 0,0008 $ за минуту образца |
| Картинка | Seedream 4.0 | 0,03 $ за картинку |
| Видео | Seedance 1.0 Pro Fast | 0,0216 $/с в 720p |
| Замена лица | PixVerse Swap | 0,20 $ за клип до 5 с |

Другие модели для каждой задачи, с ценами, — в меню моделей и в разделе [Настройка ИИ и цены](../ai.md).

## Липсинк по шагам

1. Выделите клип с лицом и нажмите <kbd>⌥L</kbd> (или **«Липсинк…»** в меню клипа, или <kbd>⌘K</kbd> «липсинк»). Любой из этих путей открывает инструмент «Липсинк» на вкладке инспектора **«ИИ»**.
2. Впишите, что человек должен сказать. Голос клонируется из самого клипа.
3. Нажмите <kbd>⌘</kbd><kbd>↵</kbd>.

- Отправляются только участки с речью, и обратно поверх ваших исходных кадров вклеивается только лицо. Поэтому трёхминутный клип, в котором 64 % тишины, стоит **60 ¢ вместо 90,5 ¢**.
- Реплика 2–24 с на модели по умолчанию стоит **20 ¢**.
- Новые слова заменяют старую речь. Клип принимает длину нового голоса, следующие клипы сдвигаются по магниту, одно <kbd>⌘Z</kbd> отменяет всё.
- Можно запустить несколько клипов сразу: три обрабатываются параллельно, остальные ждут в очереди. Оплаченный запуск не прерывается, даже если закрыть приложение.
- Сначала можно сделать **«Пробу»** на 3 секунды (примерно 2,6 ¢) — она играет прямо в панели. В списке моделей у каждой видна цена для этого клипа.
- Каждый результат — **дубль** клипа. <kbd>⇧⌥L</kbd> переключает оригинал и дубль, **«Ещё дубль»** делает следующий. Янтарная метка показывает, где губы перестали совпадать со звуком.
