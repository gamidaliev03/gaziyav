# ИИ: ключ и цены

[English](../en/ai.md) · **Русский**

Своего ИИ на продажу у Gaziyav нет. ИИ для монтажа — субтитры, удаление пауз, очистка голоса и остальное — работает [бесплатно на вашем Mac](manual/ondevice-ai.md), а [Claude](manual/claude.md) — через приложение Claude, которым вы уже пользуетесь. Эта страница — про **платные модели по желанию**: они работают через **ваш собственный аккаунт** у поставщика, по **его прайсу**, и цена видна до нажатия. Без ключа редактор работает полностью — ждут ключа только платные кнопки.

## Ключ за 2 минуты

1. Заведите аккаунт на [fal.ai](https://fal.ai), положите на него несколько долларов и создайте API-ключ в личном кабинете.
2. В Gaziyav: **Настройки → ИИ → fal.ai**, вставьте ключ, **«Сохранить»**.

На macOS ключ шифруется системной связкой ключей (Electron `safeStorage`) и лежит в папке данных приложения с правами только для владельца. Он не попадает ни в логи, ни в окружение, а интерфейс показывает только четыре последних символа. С ключом «Настройки» показывают и **живую** цену каждой модели, и ваш баланс.

Там же по желанию: ключ **kie.ai** (собственный липсинк ByteDance, голоса ElevenLabs, ещё картинки и видео) и ключ **ArgoLink** (семейство Seedance 2.0). В списках у каждой модели написано, у какого поставщика она работает; если для выбранной модели нет ключа, берётся модель того поставщика, ключ которого есть. Можно добавить и бесплатные ключи стоков **Pexels** и **Pixabay** (Викисклад работает без ключа).

## Порог расходов

**Настройки → ИИ → «Спрашивать, если дороже [1] $».** Ниже порога нажатие на кнопку с ценой и есть согласие — без диалогов. Выше — Gaziyav один раз переспросит с точной суммой. Траты считаются отдельно по каждому поставщику, по его прайсу.

## Что где работает

| Функция | Где |
|---|---|
| Монтаж, просмотр, эффекты, титры, экспорт | на вашем компьютере |
| Субтитры (распознавание речи) | на вашем Mac (Whisper), модель скачивается при первом использовании |
| Очистка голоса, разделение голоса и музыки, смена голоса, удаление объектов | на вашем Mac, модели скачиваются при первом использовании |
| Липсинк, голос, клон, картинки, видео, замена лица, агент | у поставщика (fal.ai или kie.ai / ArgoLink с их ключами) |

Что именно отправляется — в разделе [Приватность](privacy.md).
