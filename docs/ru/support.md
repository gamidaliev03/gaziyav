# Поддержать проект

[English](../en/support.md) · **Русский**

Gaziyav бесплатный и таким останется. Ничего из этого не обязательно.

## Без денег

- **Поставьте звезду репозиторию** — так его находят другие.
- **Покажите его одному человеку**, который монтирует, ведёт подкаст или снимает рилсы.
- **Сообщайте о поломках** с шагами — каждая повторимая ошибка становится тестом.
- **Переводите и правьте документацию** — пулл-реквесты приветствуются.
